# SY — Chante Groenewald Physiotherapy website concept

A responsive, dependency-free static website based on the supplied Instagram handle `sy.cgphysio`.

## Run locally

From `/workspace/Chante-Website-Build`:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

The website uses plain HTML, CSS and JavaScript. No installation or build step is required. The site uses system fonts and works without external assets. The hero illustration is included inline.
